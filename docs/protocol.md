# 第一版实验协议

此协议对应VOGUE小规模情境评分任务，不是购买序列、CTR或CVR。用户确认先完成此闭环。目录为36件图文商品，3个类别；每次场景候选是完整的12件对应类别商品，不是随机采样候选，也不是全电商商品库。

## 数据与输入

调查前的profile ratings针对商品37—76，与预测目标商品1—36不重叠。用户特征为profile高评分商品的图像特征加权平均，权重max(rating-3,0)，全无高分则使用所有已评分profile图片平均。场景文本来自预设情境，商品文本仅product_name/about_product，不使用评分汇总、review摘要、对话中的最终推荐答案。目标标签来自Seeker评分，不使用Assistant预测评分。

划分按用户固定：s1—s6训练，s7—s8验证，s9—s10测试，各36/12/12次情境。目标商品可跨集合，是已知商品目录的未参与参数训练用户评测；用户有真实入门调查，并非完全无资料新用户。此协议不能报告商品冷启动或时间泛化。需审计跨profile/target图像重复；不伪造时间。

## 特征与训练

第一版从原图RGB缩至16×16得到768维固定像素特征；文本采用稳定SHA256词哈希256维归一化，不是预训练VLM语义表示。32维商品图像/文本MLP投影，用户塔输入profile图像和场景文本。图文相加融合；text/image消融保留同一用户输入，因此只表示商品模态消融。图像原始细节丢失、词哈希冲突是重要限制。

召回使用温度0.1的多正例softmax损失，rating>=4为正例，对正例log概率求平均；其他候选进入分母但不宣称真实不喜欢，无正例情境不训练召回。排序使用rating>=4与<=2的真实评分两两softplus损失，3分不作为明确负反馈；冻结召回编码，完整类别候选构造排序训练对，避免在同训练样本上用过拟合top-k制造候选。推理先召回6件再排序。

AdamW学习率0.001、weight_decay0.001；召回100 epoch，排序60 epoch。seed42/43/44，各text/image/multimodal共9次。每次仅按验证NDCG@3选checkpoint，最终服务运行同样仅按验证选。固定训练预算，不根据测试追调。

## 指标

Recall@3/@6正例阈值4，无正例情境排除其Recall分母并报告数量；NDCG用2^(rating-1)-1分级增益，所有情境计入。排序报告召回top6重排后在原12候选定义上的端到端NDCG与Recall；排序不能补回漏召回，Recall@6应不变。查询均值，每个用户6次；仅2名测试用户，不能将12条相关情境当成12名独立用户或宣称统计显著。

基线：训练用户平均评分的商品排序、场景词哈希相似度。三种商品模态与3个种子构成消融。改进由助手实现，尚无用户提出并验证的新算法；不声称是用户原创或一定提升。

## 服务

只绑定127.0.0.1，CPU推理，默认端口8765；版本按模型/索引/特征/服务metadata SHA256校验，启动时重新编码核对索引一致性。未知用户使用训练用户profile均值回退。输入长度/类型/范围检查。GET /health，POST /recommend，GET /私有演示。分数是相对偏好分数，不是概率。
