# 本机性能报告

Apple M5 MacBook Air，24GB统一内存，macOS arm64，PyTorch2.8.0，CPU推理/1个计算线程。36件目标商品、32维索引；每情境12候选→Top6→Top3。

测试：localhost HTTP POST，20次预热，200次请求/并发设置，线程客户端闭环，不含离线图像编码；仅warm结果，不含加载/下载、公网网络或长期负载。

- 并发1：p50 0.642ms，p95 2.441ms，p99 5.025ms；吞吐1074.7请求/s，错误0/200。
- 并发4：p50 1.639ms，p95 2.560ms，p99 2.955ms；吞吐2335.1请求/s，错误0/200。

测试后服务进程峰值RSS 202850304字节（macOS ru_maxrss），不是GPU显存；GPU未用于服务，显存不适用。
原始向量数据36×32×4=4608字节，npy文件4736字节，模型文件588295字节。

200次请求不能证明生产容量/SLA；并发与低延迟受线程调度影响，不将本地数字外推企业流量。新Python进程单次测量：模块导入465.66ms，模型加载/校验4.17ms，首次引擎推理0.28ms；这是引擎加载测量，不是HTTP服务从启动到ready的完整耗时。

健康检查、非法场景HTTP400、演示HTML、图片路由和未知用户回退已验证。服务未注册守护进程，应用/进程退出后可能需要按部署说明重启。
