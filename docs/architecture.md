# 第一版架构

离线：官方评分/商品PNG/JSON → ID与内容审计 → 固定用户分组 → 原图RGB特征/词哈希 → 多正例双塔训练 → 验证选权重 → 冻结编码器训练pairwise MLP排序 → 32维商品索引与版本哈希。

在线：user_id/scenario → 入门偏好图像聚合/场景词哈希 → 用户塔 → 在该场景完整12件类别目录精确检索 → Top6 → 排序器 → TopK → 本机HTTP与简单页面。

张量：商品图像[36,768]、文本[36,256]、索引[36,32]；单请求历史[1,768]、场景[1,256]、用户向量[1,32]、候选[12,32]；排序拼接用户/商品/逐元素乘积/绝对差[6,128]→[6,64]→[6]。

文件版本用SHA256管理，启动重编码验证索引。线上不读取目标评分、不执行图片编码，服务用已缓存索引；用户输入来自独立入门调查。原始数据和权重放在Git忽略目录，只有本机副本。

本版不包含分布式训练、实时特征流、线上A/B、生产鉴权与SLA。固定低分辨率像素和词哈希是轻量基线，不能描述为预训练VLM理解能力或VLM2Vec微调。本版实现借鉴对比双塔/排序思想，无直接复制两仓库源码。后续替换为许可明确的小型预训练编码器，并扩大真实数据，需新实验而不是更新宣传名称。
