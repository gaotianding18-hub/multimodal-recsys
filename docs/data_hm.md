# H&M 数据核验

2026-10-11。用户本人注册并接受竞赛规则，通过官方页面下载CSV，助手解压交易与用户数据。用途为非商业学习研究；不分发原数据，不提交竞赛结果。

原始数据存data/hm/raw，Git忽略。交易ZIP为612,670,986字节，CSV为3,488,002,253字节，流式解压读取通过ZIP CRC验证。三份CSV的SHA256及完整按日计数见reports/hm_audit.json，可用`.venv/bin/python scripts/audit_hm.py`复核。

实测31,788,324行购买记录，105,542个目录商品，1,371,980个用户；交易涉及1,362,281个用户与104,547个商品。时间为2018-09-20至2020-09-22。全部交易商品、用户可在元数据关联，未发现未知ID，ID和日期长度检查通过（并非所有字段的完整语义校验）。416件商品缺少描述。缺描述不直接删除商品；仍可使用名称与属性。

交易字段：t_dat/customer_id/article_id/price/sales_channel_id。article_id按字符串保留前导零。购买是正反馈，未购买不等于不喜欢；没有曝光分母，不做CTR/CVR。官方说明重复交易行可表示同商品多次购买，不以重复行直接认定脏数据。日期精度为天，同日商品不推断先后关系。

拟采用最近训练窗口2020-06-17至2020-09-08、验证周09-09至09-15、测试周09-16至09-22。这是待实现协议，尚无模型指标。历史只能来自查询日期之前；同日购买作为集合。商品候选以各评测窗口开始前的可观测商品构造，报告目标在候选的覆盖率。目录为静态快照，客户属性也缺历史版本；初版不使用客户静态属性避免将当前状态解释成历史特征。购买商品重复出现有意义，不机械屏蔽已购商品。

下一步根据训练期分布确定可承担子集；不能用测试期热度挑选商品或用户。商品图片仍未下载，图文训练未开始。数据缺图比例、近重复图片、属性/图片版本泄漏限制还需核查。
